СИСТЕМА УЧЁТА ПРОДАЖ МАГАЗИНА БЫТОВОЙ ТЕХНИКИ
==========================================

FastAPI-проект для лабораторных работ.
Реализует учёт товаров, клиентов и продаж, а также полный набор автотестов:
unit, BDD, GUI (без Selenium) и нагрузочное тестирование.

--------------------------------------------------
ВОЗМОЖНОСТИ
--------------------------------------------------

• Управление товарами (CRUD, поиск, валидация)
• Оформление продаж с расчётом total_amount
• Фильтрация продаж по датам
• Статический GUI (HTML + JS)
• Автоматизированное тестирование
• Нагрузочное тестирование API

--------------------------------------------------
БЫСТРЫЙ СТАРТ
--------------------------------------------------

1. Виртуальное окружение

Windows PowerShell:
python -m venv .venv
.venv\Scripts\Activate.ps1

Linux / macOS:
python3 -m venv .venv
source .venv/bin/activate

2. Установка зависимостей

pip install -r requirements.txt

3. Инициализация базы данных и демо-данных

python -m app.seed

Будет создан файл sales.db (SQLite)

4. Запуск API

uvicorn app.main:app --reload

Swagger UI:
http://127.0.0.1:8000/

--------------------------------------------------
СТРУКТУРА ПРОЕКТА
--------------------------------------------------

app/
  main.py            — точка входа FastAPI
  database.py        — подключение SQLite
  models.py          — SQLAlchemy модели
  schemas.py         — Pydantic схемы
  crud.py            — бизнес-логика
  seed.py            — демо-данные
  routers/
    products.py
    customers.py
    sales.py

static/
  index.html         — GUI
  style.css
  script.js

tests/
  unit/              — unit-тесты (pytest)
  bdd/               — BDD-сценарии (pytest-bdd)
  ui/                — GUI-тесты (static HTML/JS)
  load/              — нагрузочные тесты (Locust)

--------------------------------------------------
ИНСТРУМЕНТЫ ТЕСТИРОВАНИЯ (5.2)
--------------------------------------------------

• Юнит-тесты: pytest
• BDD-тестирование: pytest-bdd
• GUI-тесты: pytest
• Нагрузочное тестирование: Locust
  (альтернатива: k6 / JMeter)



--------------------------------------------------
ЗАПУСК ТЕСТОВ
--------------------------------------------------

Юнит-тесты:
pytest -q tests/unit

BDD:
pytest -q tests/bdd

GUI (static):
pytest -q tests/ui

--------------------------------------------------
НАГРУЗОЧНОЕ ТЕСТИРОВАНИЕ (Locust)
--------------------------------------------------

1. Запустить API:
uvicorn app.main:app --reload

2. Запустить Locust:
locust -f tests/load/locustfile.py --host=http://127.0.0.1:8000

3. Открыть в браузере:
http://127.0.0.1:8089

В отчёте демонстрируются:
• Summary
• Statistics (по эндпоинтам)
• Latency / RPS
• Failures (при наличии)
